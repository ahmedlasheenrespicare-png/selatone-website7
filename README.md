# صله تون | حلول السمع والمعينات السمعية

موقع تسويقي عربي (RTL) لشركة **صله تون** الطبية المتخصصة في حلول السمع والمعينات السمعية منذ 2014.
صفحة واحدة تفاعلية: اختبار سمع استرشادي، مساعد اختيار المعين السمعي، دليل البطاريات، طلب صيانة عبر واتساب، وأكثر.

## ✨ المزايا

- **عربي بالكامل RTL** — خصائص منطقية (`ps-`/`me-`/`start-`/`end-`) وأسهم معكوسة تلقائيًا
- **اختبار سمع استرشادي** — 5 أسئلة مع نتيجة فورية وإخلاء مسؤولية طبي
- **مساعد اختيار المعين السمعي** — توصية مبدئية حسب العمر والأولوية والطاقة والاتصال
- **نماذج عبر واتساب** — الصيانة، الحجز، التقييمات، ومعاودة الاتصال تُرسل برسائل جاهزة إلى `wa.me`
- **أزرار عائمة** — واتساب بنافذة «تواصل سريعًا» (6 خدمات) + فيسبوك
- **إمكانية وصول (a11y)** — `aria-live`، فخ تركيز، `role="dialog"`، احترام `prefers-reduced-motion`
- **بناء ملف واحد** — `vite-plugin-singlefile` يُخرج `dist/index.html` واحدًا مكتفيًا ذاتيًا

| | |
|---|---|

## 🚀 التشغيل

```bash
npm install       # تثبيت الاعتماديات
npm run dev       # خادم التطوير
npm run build     # بناء الإنتاج إلى dist/
npm run preview   # معاينة نسخة الإنتاج
```

## 📁 بنية المشروع

```
├── index.html                  # نقطة الدخول (RTL + خط Cairo)
├── src/
│   ├── App.tsx                 # ترتيب الأقسام
│   ├── data.ts                 # الأرقام، روابط واتساب، الصور، الأنماط المشتركة
│   ├── index.css               # ثيم Tailwind + الأنماط المخصصة
│   ├── components/
│   │   ├── Header.tsx          # هيدر لاصق + قوائم منسدلة + قائمة جوال
│   │   ├── Hero.tsx            # سلايدر تلقائي + صناديق الخدمات
│   │   ├── Sections.tsx        # من نحن، إحصائيات، اختبار السمع، المنتجات، مساعد الاختيار
│   │   ├── Sections2.tsx       # مقارنة، تقنية، بطاريات، صيانة، علامات، عروض
│   │   ├── Sections3.tsx       # مقالات، تقييمات، أسئلة شائعة، تواصل
│   │   ├── FloatingActions.tsx # أزرار واتساب/فيسبوك العائمة + نافذة الخدمات
│   │   ├── Footer.tsx / Reveal.tsx / Icons.tsx
│   └── utils/cn.ts
└── scripts/preview/            # بناء نسخة معاينة مكتفية ذاتيًا (صور وخطوط مدمجة)
```

## 📦 سكربت المعاينة المكتفي ذاتيًا

```bash
python3 scripts/preview/build_preview.py
```

يبني نسخة HTML واحدة تدمج الصور (WebP) وخط Cairo داخل الملف — مفيدة للمشاركة دون استضافة.
